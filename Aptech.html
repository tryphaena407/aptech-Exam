Chapter 1 — Understanding Search Engine & SEO Components

1. SEO stands for:
A) Search Engine Operation
B) Search Engine Optimization
C) Search Engine Organization
D) Search Entry Optimization
✅ Answer: B

2. What is the primary purpose of SEO?
A) To design computer hardware
B) To improve a website's visibility in organic search results
C) To create mobile applications
D) To increase internet speed
✅ Answer: B

3. Which of the following is a search engine?
A) Google
B) Photoshop
C) MS Word
D) MySQL
✅ Answer: A

4. What is a crawler/spider?
A) A human who reviews websites
B) An automated program used by search engines to crawl the Web and gather data
C) A website designer
D) A database administrator
✅ Answer: B

5. What does a crawler generally collect from a website?
A) Computer hardware information
B) Website information such as text and its location
C) User passwords
D) Operating-system files
✅ Answer: B

6. After gathering information, search engines store it in their:
A) Browser
B) Database/index
C) Keyboard
D) Control panel
✅ Answer: B

7. What is the purpose of indexing?
A) To delete websites
B) To organize and store information gathered by crawlers
C) To design web pages
D) To create advertisements
✅ Answer: B

8. Search engines use algorithms to:
A) Rank websites in search results
B) Create computer programs
C) Edit images
D) Increase RAM
✅ Answer: A

9. What does SERP stand for?
A) Search Engine Ranking Process
B) Search Engine Results Page
C) Search Entry Results Program
D) Search Engine Resource Page
✅ Answer: B

10. Which type of search results does SEO primarily focus on?
A) Paid results
B) Organic/natural results
C) Email results
D) Offline results
✅ Answer: B

11. SEO basically has which two broad categories?
A) Local and global SEO
B) On-page and off-page SEO
C) Paid and unpaid SEO
D) Desktop and mobile SEO
✅ Answer: B

12. On-page SEO refers to:
A) Activities performed outside a website
B) Optimization performed within a website
C) Social-media advertising only
D) Paid advertising
✅ Answer: B

13. Off-page SEO refers to:
A) Activities performed outside the website
B) Changing HTML headings only
C) Designing website images
D) Writing CSS
✅ Answer: A

14. Which of the following is an important SEO component?
A) Keyword research
B) Computer assembly
C) Printer configuration
D) Operating-system installation
✅ Answer: A

15. What is a sitemap mainly used for?
A) Helping search engines discover/crawl website pages
B) Increasing computer memory
C) Creating advertisements
D) Designing logos
✅ Answer: A

16. Which format is commonly used for a sitemap?
A) XML
B) JPG
C) MP3
D) EXE
✅ Answer: A

17. What is keyword stuffing?
A) Removing all keywords from a page
B) Repeating keywords excessively to try to improve ranking
C) Researching new keywords
D) Translating keywords
✅ Answer: B

18. Which of the following is a search-engine SEO misconception?
A) SEO involves optimization
B) Search engines use crawlers
C) SEO is only about choosing keywords
D) Content is important for SEO
✅ Answer: C

19. According to the chapter, what is becoming increasingly important for SEO?
A) User intent
B) Computer hardware
C) Printer speed
D) Screen resolution
✅ Answer: A

20. Which sequence best describes how a search engine handles web information?
A) Rank → Crawl → Index
B) Crawl → Index → Rank
C) Index → Delete → Crawl
D) Search → Design → Crawl
✅ Answer: B
